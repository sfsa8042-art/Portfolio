# Artemiy Fomkin — Portfolio

Dark, minimal single-page portfolio. React + Vite + TypeScript + Tailwind + GSAP + Framer Motion.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно http://localhost:5173).

## Сборка

```bash
npm run build      # собирает в /dist
npm run preview    # локальный предпросмотр сборки
```

## Как редактировать контент

Почти весь текст, проекты и статистика — в одном файле:

```
src/data/content.ts
```

Там меняешь:
- `profile` — имя, роли (циклятся в hero), tagline, email;
- `about` — блок «About» и список интересов;
- `projects` — карточки в разделе Work (заголовок, описание, теги, год, ссылка, ширина `md:col-span-*`);
- `stats` — три цифры внизу About (заполни, когда будут реальные);
- `socials` — ссылки на соцсети в футере (сейчас пустой массив — просто добавь объекты).

## Структура

```
src/
  data/content.ts        ← весь редактируемый контент
  components/
    LoadingScreen.tsx    ← прелоадер (счётчик 000→100)
    Navbar.tsx           ← плавающая навигация
    Hero.tsx             ← первый экран, GSAP-вход, градиентный фон
    Work.tsx             ← bento-сетка проектов
    About.tsx            ← о себе + интересы + статистика
    Contact.tsx          ← CTA, marquee, футер
    Emphasis.tsx         ← утилита: *слово* → курсивный акцент
  App.tsx
  main.tsx
  index.css              ← токены, шрифты, анимации
```

## Детальные страницы проектов

Клик по любой карточке разворачивает **страницу-профиль проекта** (оверлей со своим скроллом): tagline, роль, обзор, метрики, функционал, галерея реальных скринов и кнопки на живые сайты/материалы. Закрытие — крестик, кнопка «Back» или клавиша Esc.

- **APEX** — подробное описание, весь функционал (delta timing, track heatmap, AI-инженер, десктоп-клиент и т.д.), **реальные скриншоты** (hero, телеметрия Monza/Porsche, дашборд, база машин, база трасс) в `public/shots/apex_*.jpg`, кнопки на живой сайт / дашборд / академию. Есть «Load live preview» — встраивает реальный сайт в iframe (если сайт разрешает встраивание; если нет — открывается в новой вкладке).
- **NFQ** (ключевой, флагманский проект — стоит первым и помечен бейджем «Award-winning») — подробное описание методологии, 6 фич, метрики, и большая галерея **реальных материалов**, сгруппированная по категориям:
  - *Landing site* — 7 скринов лендинга,
  - *Compliance report* — обложка + реестр нарушений,
  - *Pitch deck* — 7 слайдов,
  - *Methodology (NFQ Standard v2.0)* — методология, чек-лист, NFQ Score,
  - *Business plan* — конкуренты, бизнес-модель, финансы,
  - *Awards* — 3 награды (грамота «Шаг в бизнес», диплом «Наука для жизни» Финуниверситета, диплом призёра «Творчество юных» МИЭТ) — оригинальные сканы с английскими подписями-переводами.

  Плюс кнопки, открывающие исходники (сайты + PDF). Материалы на русском (реальные документы), подписи — на английском.

Реальные скрины лежат в `public/shots/` (сняты с настоящих сайтов). Все тексты детальных страниц редактируются в `src/data/content.ts` → поле `detail` у каждого проекта.

> Примечание: сайт APEX может блокировать встраивание в iframe (это его настройка, X-Frame-Options) — тогда live-preview не откроется внутри страницы, но кнопки «открыть в новой вкладке» работают всегда.

## Заметки

- Шрифты: дисплейный **Fraunces** (italic) + **Inter** для текста + **JetBrains Mono** для цифр/меток.
- Прелоадер: имя собирается по буквам с blur-reveal, растущая линия-прогресс, на выходе — «занавес» вверх.
- Карточки проектов содержат **реалистичные SVG-превью** продуктов (`src/components/Mockups.tsx`), построенные по реальным данным: телеметрия APEX (Monza/Porsche, gap −1.241s), отчёт NFQ (Score 58→86, экспозиция 640 000 ₽), скоринг рынков EntryLens. Мокап проекта задаётся полем `mockup` в `content.ts`.
- Видео-фон из исходного промпта заменён на тихий анимированный градиент (минимализм, без hls.js).
- Синий акцент `#89AACC → #4E85BF` задан классом `.accent-gradient` в `index.css`.
- Уважается `prefers-reduced-motion`.
- Проекты сейчас: EntryLens, NFQ, APEX (ссылка на живой сайт) + плейсхолдер под четвёртый.

### Заменить мокап на настоящий скриншот

Если захочешь вставить реальный PNG-скрин вместо SVG-мокапа: положи картинку в `public/`, и в `Work.tsx` замени `<Mock />` на `<img src="/screenshot.png" className="w-full h-full object-cover" />` для нужной карточки.
